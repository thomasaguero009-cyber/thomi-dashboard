🔄 Cómo actualizar estos datos

Estos datos no se sincronizan solos — viven como un archivo dentro de este mismo repositorio de GitHub. Para actualizarlos: en ManyChat, abrí el ícono de la extensión → Opciones → sección "Thom.i — aprendizaje" → botón Exportar JSON, y pasale ese archivo a Claude para que lo suba acá.
